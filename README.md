# Painel do Carro: versões

Versões publicadas do app **Painel do Carro** (Android), que lê o carro pela tomada OBD2 com um adaptador
ELM327 Bluetooth: painel, avisos, códigos de falha, laudo de compra, consumo e histórico.

Este repositório só tem os instaladores (em **Releases**) e as notas de cada versão. O código-fonte é privado.

## Instalar ou atualizar

- Pelo próprio app: **Mais → Sobre e atualizações**. Ele confere aqui uma vez por dia e instala com um toque.
- À mão: abra o release mais recente, baixe o `painel-carro.apk` e abra no celular (permita instalar apps
  desta fonte quando o Android pedir).

O app só instala por cima se a assinatura for a mesma da versão instalada.
